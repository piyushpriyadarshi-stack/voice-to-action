# Voice-notes-to-Action-Items
# 🎙️ Voice2Action

> AI-powered meeting assistant that converts meeting audio into transcripts, summaries, key points, and actionable tasks.

## 🚀 Live Demo

👉 **[Open Voice2Action](https://voice-to-action-c9wgq3ps3ghucyosxqxz7t.streamlit.app/)


🌐 The application is publicly accessible from any device with an internet connection.
## 📌 Features

- 🎤 Voice recording and audio input
- 📝 Automatic speech-to-text transcription
- 🤖 AI-powered analysis
- ✅ Extraction of action items and tasks
- 📋 Organized and easy-to-read results
- 💾 Local data storage
- ⚡ Simple and user-friendly Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Faster-Whisper
- SQLite
- AI / NLP
- Git & GitHub
